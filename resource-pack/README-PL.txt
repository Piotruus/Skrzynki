PACZKA ZASOBÓW — SKRZYNKI 3D (Minecraft Java 1.21.4)

Warianty: Flowybox (turkus + złoto), Rzadka (zieleń), Epicka (fiolet), Legendarna (złoto).
Modele bazują na CustomModelData 9101–9108 na przedmiocie PAPER.

WAŻNE: paczka sama nie zamienia postawionego bloku CHEST w model 3D. Plugin musi tworzyć ItemDisplay z przedmiotem PAPER i odpowiednim CustomModelData oraz osobno animować model wieka. Obecny kod pluginu wymaga tej integracji.
